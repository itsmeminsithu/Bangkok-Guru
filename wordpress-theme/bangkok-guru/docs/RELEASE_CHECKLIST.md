# Bangkok Guru Production Checklist

- [ ] Install on staging WordPress with required PHP version and database configuration.
- [ ] Run WordPress theme checks and a PHP fatal/error log scan.
- [ ] Import 4 pages, switch selected home, and verify no existing content was overwritten.
- [ ] Upload the original logo and compare light/dark header/footer legibility.
- [ ] Add a real journey / destination / day experience; set every field and all 3 layouts.
- [ ] Test `20 seats`, simultaneous `15+10 travellers`, overselling prevention and waitlist; test late cancellations and refunds.
- [ ] Verify early-bird cut-off in WordPress site timezone and balance date in correct local timezone.
- [ ] Run WooCommerce deposit order in sandbox, pay, generate balance order, pay, inspect states; test gateway fee-item and order-pay compatibility.
- [ ] Test late payment after an expired hold; confirm `manual_review` and manual customer outreach.
- [ ] Configure reliable system WP-Cron, SMTP delivery, backups, HTTPS and relevant privacy notices.
- [ ] Check responsive mobile booking flows, keyboard navigation and RTL pages.
- [ ] Test all four Elementor widgets including their Style tabs and optional Kit sync (staging copy first).
- [ ] Confirm legal travel agency terms, local tourism regulatory obligations, invoices/taxes and refund policy.
- [ ] Review destination imagery, fonts, logos and translation rights.
- [ ] Do not accept real payments until the above tests pass.
