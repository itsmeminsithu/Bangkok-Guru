# Bangkok Guru — WordPress တင်သွင်းနည်း (v0.12)

၁။ WordPress Database နဲ့ `wp-content` ကို Backup လုပ်ပါ။
၂။ **Appearance → Themes** မှာ Bangkok Guru **Theme v0.12** ကို အရင် Update လုပ်ပါ။
၃။ **Plugins → Add New → Upload** မှာ `Bangkok-Guru-Bookings-Plugin-v0.12.0.zip` ကို Upload / Activate လုပ်ပါ။
၄။ **Settings → Permalinks → Save Changes** နှိပ်ပါ။
၅။ Appearance → Bangkok Guru Setup မှာ Homepage Demo ၄ မျိုးထဲက ရွေးပါ။
၆။ WooCommerce လိုပါက သီးခြား Install လုပ်ပြီး Gateway ကို Sandbox/Test Mode နဲ့ အရင် စမ်းသပ်ပါ။

Mac Terminal Preview: GitHub Source ZIP Extract → `./scripts/start-mac.sh` → `http://localhost:8188` မှ WordPress Installer → `./scripts/enable-theme.sh`။ Test email ကို `http://localhost:8189` မှာ ကြည့်နိုင်ပါတယ်။
