# Demo Preview → Real Customer Website checklist

- [ ] Theme and independent Bookings Plugin are both at v0.13.0.
- [ ] Select homepage and confirm 18 example entries, pages, media, links, menus.
- [ ] Replace demo brand copy and sample blog text with actual business information.
- [ ] Use owned/licensed photographs in place of included original illustrations.
- [ ] Replace example prices and departures with actual offers, contract terms and inventory.
- [ ] **Only then:** explicitly switch each trip from preview to live (server denies all demo booking posts).
- [ ] Review cancellation, refund and deposit contract terms with qualified counsel as applicable.
- [ ] Set WooCommerce shop currency and real/sandbox payment gateway appropriately.
- [ ] Create and publish authentic Privacy Policy, Cookie Policy and Terms of Booking. Configure WordPress Settings → Privacy.
- [ ] Configure transactional email SMTP and send a real test message; verify customer email confirmation.
- [ ] Add real operator contact address, phone, business registration and applicable regulatory information.
- [ ] Enable and test backups; limit admin permissions; use 2FA, SSL, updates and a WAF/rate limits.
- [ ] Configure caching, image optimisation, SEO sitemap and Search Console.
- [ ] Test mobile, tablet, accessibility and RTL page previews.
- [ ] Complete WooCommerce sandbox tests: deposit, balance, chargebacks/refunds and callback expiry.
- [ ] Test simultaneous bookings with low seats and post-payment inventory reconciliation.
- [ ] Use HTTPS, password-protected staging for customer previews until production readiness.

**Note:** Demo material is illustrative, not evidence of a tour operator licence, a confirmed itinerary or available transport. Theme activation does not automatically publish legal guarantees. Existing site data is never wiped by the demo installer.
