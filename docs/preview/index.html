Install on WordPress (v0.13.0)

  1. Download Bangkok-Guru-WordPress-Theme-v0.13.0.zip from the release.
  2. WordPress admin → Appearance → Themes → Add New → Upload Theme → Activate.
  3. Download Bangkok-Guru-Bookings-Plugin-v0.13.0.zip from the same release.
  4. WordPress admin → Plugins → Add New → Upload Plugin → Activate.
  5. Follow the demo import prompt, or go to Appearance → Bangkok Guru Setup.
